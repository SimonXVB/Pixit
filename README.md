# Pixit
Pixit is a simple, lightweight Pixel-Art-Creator. Written in **Python + Pygame.**

## Features:
- Drawing
- Deleting
- Selecting
- Copy/Paste/Resize
- Loading/Saving image files
- Accepted image formats: **".bmp", ".png", ".jpeg"**

### Notes:  
This repo houses the code for my first python project (which was kind of a disaster and took me 3 months to create :))) ).  
I initially wanted to use Tkinter for this project, but then I quickly realized that the Tkinter canvas wasn't that optimal for a project like this (+ the docs sucked), so I moved everything over to Pygame.
